# Ski areas in 3D: Jikepulin (Hemu) and Jiangjun Shan

Interactive 3D map of two ski areas in Xinjiang, China. Open the page, drag to rotate, scroll to zoom, click a run, lift or the ground for details.

Data and credits:
- Runs and lifts: © OpenStreetMap contributors (ODbL), processed by OpenSkiMap / OpenSkiData.
- Terrain: AWS Terrain Tiles (SRTM, ASTER and other public elevation sources).
- 3D rendering: three.js (MIT licence).
